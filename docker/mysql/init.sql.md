# `init.sql` 讲解

## 作用概览

该脚本初始化聊天系统关系模型，包含用户、好友、群、群成员和离线消息五张表，并通过主键、外键和索引保证基本一致性与查询效率。

## 按学习顺序讲解

1. 数据库：使用 `utf8mb4`，可完整保存中文和四字节 Unicode 字符。
2. `user`：自增用户 ID、昵称、最长 100 字节的密码哈希和在线状态。在线状态是持久化视图，Redis 还保存带 TTL 的节点路由。
3. `friend`：联合主键防止同方向好友关系重复；两个外键均级联删除。本项目添加好友是单向记录。
4. `allgroup`：保存群名称和描述。
5. `groupuser`：以 `(groupid, userid)` 防止重复入群，`grouprole` 区分创建者和普通成员。
6. `offlinemessage`：每条消息单独存储，`BIGINT` 自增 ID 决定稳定顺序；`(userid,id)` 索引支持按用户顺序拉取。

本文件无函数，重点在约束、索引和表间关系。

## 面试重点

重要性高。常见问题：为什么离线消息不能只按用户存一个大字符串？独立行更易排序、扩展和故障恢复；如何保证离线消息顺序？查询按自增 `id`；有什么不足？好友缺少双向事务，离线消息当前是先查后删，严格可靠场景应引入消费状态或确认机制。
