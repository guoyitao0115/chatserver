# `完整回归与压力测试.sh` 讲解

## 作用概览

这是最完整的自动验证入口，顺序执行 C++ 核心测试、网关测试、端到端测试、可靠性测试、压力测试以及 RabbitMQ/MySQL 故障注入。

## 按学习顺序讲解

1. 读取脚本目录并进入根目录，保证相对路径稳定。
2. `ctest` 验证帧协议、去重和配置读取等不依赖外部服务的逻辑。
3. `npm test` 验证网关；`test:e2e` 验证正常双节点链路。
4. `test:reliability` 检查重复登录、身份冒用、去重、不丢、顺序、离线恢复等性质。
5. `test:load` 统计并发消息吞吐、成功率和延迟分位数。
6. 两个 chaos 命令暂停并恢复 RabbitMQ/MySQL，验证降级与恢复行为。

## 面试重点

重要性高。可能问题：为何测试按此顺序？先运行便宜、定位清晰的测试，再运行耗时且会改变容器状态的故障测试；压测结果为什么不能直接代表生产容量？本机资源、数据规模、连接模型和监控开销均与生产不同。
