# `全链路测试.sh` 讲解

## 作用概览

该脚本先检查 Docker Compose 服务状态，再运行 Web 网关单元测试和双节点端到端测试，是快速验证主链路的入口。

## 按学习顺序讲解

1. 严格 Shell 模式保证错误立即暴露。
2. 根据脚本位置切换到项目根目录。
3. `docker compose ps` 展示依赖与服务状态。
4. `npm test` 验证 WebSocket/TCP 网关协议桥接。
5. `npm run test:e2e` 验证注册、登录、聊天及跨节点路径。

## 面试重点

重要性中等。可说明这是 smoke/E2E 入口，不替代可靠性、故障注入和压力测试。
