# `index.html` 讲解

## 作用概览

该文件定义单页聊天界面的语义结构，不包含业务逻辑。页面分为认证视图、聊天视图、添加会话对话框和 toast，DOM ID 是 `app.js` 的绑定契约。

## 按学习顺序讲解

1. `head`：声明中文、移动端 viewport、项目描述，加载样式。
2. 背景与 `.shell`：纯装饰层和页面布局容器。
3. `#auth-view`：品牌介绍、登录/注册 tab、两张表单、连接状态。输入约束与后端昵称/密码限制对应。
4. `#chat-view`：左侧个人资料、好友/群组列表和新会话按钮；右侧当前会话、消息区域与发送表单。
5. `#action-dialog`：同一个原生 dialog 根据模式承担加好友、加群或建群。
6. `#toast`：无阻塞反馈；末尾以 module 方式加载 `app.js`。

本文件没有 JavaScript 函数，事件行为见同目录 `app.js.md`。

## 面试重点

重要性较低到中等。可能问题：为何使用语义标签和 ARIA？提升可访问性；为什么脚本放末尾且用 module？DOM 已可用，ES module 默认 defer。
