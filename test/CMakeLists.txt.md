# `test/CMakeLists.txt` 讲解

## 作用概览

该文件构建不依赖 MySQL/Redis/RabbitMQ 的 C++ 核心测试，并把它注册到 CTest。

## 按学习顺序讲解

1. `add_executable(chat_core_tests ...)`：生成独立测试程序。
2. include 路径提供帧协议、配置和去重器头文件。
3. 链接线程库，因为并发去重测试会创建 32 个线程。
4. 开启严格警告。
5. `add_test` 让顶层 `ctest` 能发现并运行该程序。

本文件无业务函数。

## 面试重点

重要性中等。可能问题：为什么核心测试不依赖外部服务？运行快、结果稳定、失败定位清楚；集成能力再由 Web E2E/可靠性测试覆盖。
